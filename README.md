# Network Checklist of Prof. Messer For Cybersecurity

A single-page, self-contained checklist for tracking progress through Professor Messer's Network+ video course. Built as a static HTML page — no build step, no dependencies.

## Features

- Interactive checklist covering the Network+ video series
- Progress tracking with priority indicators (high / medium / low)
- Dark, terminal-inspired UI
- Works fully offline — everything lives in one `index.html` file

## Usage

Just open [index.html](index.html) in any browser, or visit the live deployment below.
